# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 已落地：坏点旁路保留

工程形态：**旁路凭证冻结**（非“匣内摘要+只读归档包”双写两轨）。

- 坏点落下生成 `BP-` 旁路凭证，坏点匣行冻结原观测时与原读数，正式观测报文字段不抹空；
- 匣行与观测报文同库事务、同成同败，禁止回刷丢字段；
- 坏点匣 `报文编号` 库级唯一索引 + 装载进程内串行闸，同号两路并发只成一匣，另一路干净幂等驳回；
- 只读回读接口 `GET /api/坏点旁路保留`：联查匣行与观测流，逐行给 `原观测可回读`（可回读/已丢失可区分）与 `同票一致`；
- 栏贯验对账灯并入坏点齐套：缺原观测时或缺读数的匣行判撕裂。
- 争用收工脚本：`scripts/并发双请求.sh`（HTTP）、`scripts/并发双请求_服务层.py`（直调服务层）。
- 测试：`backend/tests/test_keepobs_1.py`（原观测保留/同败回滚）、`test_keepobs_2.py`（对账灯）、`test_keepobs_3.py`（并发互斥）。
